# Avang VPN

Minimal, fast, and full-featured Android V2Ray/Xray VPN client.

## Features
- Real Xray Core Tunneling (VLESS, VMess, Trojan, Shadowsocks, Reality, WS, gRPC)
- Subscription Info Card (Title, Remaining Traffic, Used GB, Expiration Days)
- Auto Fastest Server Selection + Manual Server List Picker
- Clipboard & QR Code Scanner Import + Subscription Delete Manager
